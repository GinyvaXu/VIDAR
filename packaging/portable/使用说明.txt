VIDAR {{VERSION}} 便携版（Windows x64）
==========================================

【启动图形界面】
  双击 VIDAR.exe

【命令行模式】（在本目录打开终端）
  VIDAR-CLI.exe run BV号                    全流程处理
  VIDAR-CLI.exe run BV号 --from refine      从某步续跑
  VIDAR-CLI.exe model download large-v3     辅助下载 ASR 模型（推荐）
  VIDAR-CLI.exe model check large-v3        校验模型完整性
  VIDAR-CLI.exe gpu install                 N 卡加速：安装 GPU 运行时（可选）
  VIDAR-CLI.exe doctor --net                环境自检（含网络）
  VIDAR-CLI.exe --help                      全部命令

【ASR 模型】（约 3.1GB，未随包分发，二选一）
  方式一（推荐）：在本目录执行
      VIDAR-CLI.exe model download large-v3
  方式二（手动）：下载 5 个文件放入 本目录\models\faster-whisper-large-v3\
      链接与校验方式见项目 README「模型下载」

【GPU 加速】（可选，推荐 N 卡用户）
  主包为保持轻量不含 CUDA 运行时；在本目录执行：
      VIDAR-CLI.exe gpu install
  自动从 PyPI 镜像下载并安装 cuBLAS/cuDNN（约 1.2GB 下载 / 1.5GB 磁盘）。
  验证：VIDAR-CLI.exe doctor（faster-whisper 行显示 "CUDA 设备 1"）
  无 N 卡可跳过：会自动使用 CPU（速度较慢）。

【广告省略】（默认开启）
  LLM 自动识别文稿里的真广告（赞助口播/带货引导/商务植入），
  成品（原始稿/精修稿/笔记/PDF/Word/EPUB/字幕）全部省略；
  被省略内容另存「省略广告版-标题.txt」记录留档。
  关闭方式：VIDAR-CLI.exe run BV号 --no-ads（或 config.toml 中 [ads] enabled=false）

【PDF / Word / 电子书导出】（可选，图文并茂）
  VIDAR-CLI.exe run BV号 --pdf                导出 PDF（默认报刊风 + 全文）
  VIDAR-CLI.exe run BV号 --pdf --pdf-style paper    论文风（封面/摘要/目录）
  VIDAR-CLI.exe run BV号 --pdf --pdf-mode brief     精简版（3-6 页）
  VIDAR-CLI.exe run BV号 --pdf --docx         同时导出 Word（可再编辑）
  VIDAR-CLI.exe run BV号 --epub               导出 EPUB 电子书（微信读书/墨水屏）
  （关键帧+要点截图默认开启；加 --no-screenshots 可关闭）

【电子书导入微信读书】
  微信读书 App/网页版 →（电脑端）「传书到手机」→ 上传 电子书版-标题.epub，
  手机端书架上自动出现；支持多端同步进度。
  重导命令：VIDAR-CLI.exe epub BV号（--mode brief 精简 / --open 直接打开）

【模型管理】
  VIDAR-CLI.exe model list                  模型清单（大小/显存建议/安装状态）
  VIDAR-CLI.exe model recommend             按显卡显存推荐档位
  VIDAR-CLI.exe model download large-v3     下载（分片并行、断点续传、大小校验）
  VIDAR-CLI.exe model check large-v3        校验完整性

【首次配置 LLM】（3 步）
  VIDAR-CLI.exe llm presets                 查看服务商预设（含 Key 获取链接）
  VIDAR-CLI.exe llm setup deepseek --write  应用预设（或 --key sk-xxx；预览不加 --write）
  VIDAR-CLI.exe llm test                    真实连通性测试（1 token）

【批量处理】
  VIDAR-CLI.exe batch urls.txt              清单每行一个 BV 号/链接（# 注释，失败不中断）
  （可选 --stop-on-error 遇错即停；已完成任务自动跳过、可续跑）

【暂停与续跑】（GUI 任务页）
  运行中点「暂停」→ 段/请求块边界挂起（1-2 秒生效）；「继续」秒回；
  「释放显存」→ 保存检查点后退出（ASR 从已识别时间点切片续跑，LLM 各步按块续跑）。
  历史页：进度徽标一目了然；选中任务看步骤明细，可「继续」或「从选中步骤重跑」。

【语段编辑】（文章体排版）
  LLM 把零散句子编成自然段（默认 60–260 字），正文首行缩进两格；
  可在 config.toml 的 [paragraph] 调整段长上下限，或 enabled=false 关闭（回退逐句）。

【双语翻译】（外语视频自动翻译，可对照阅读）
  默认开启：语言自动检测 → 非中文视频逐段翻译为中文（1:1 对照）
  VIDAR-CLI.exe run BV号 --target-lang en     目标语言换成英文（中文视频 → 英文版）
  VIDAR-CLI.exe run BV号 --no-translate       关闭翻译
  VIDAR-CLI.exe run BV号 --no-bilingual       只出译文（不附原文）
  （译文出现在：精修稿版 / 字幕版 / 报刊版·论文版 PDF / Word版 / 电子书版）

【排版调试】（不重跑流水线，改完秒出）
  VIDAR-CLI.exe pdf BV号 --scale compact      字号档位：compact 小 / standard 标准 / large 大
  VIDAR-CLI.exe pdf BV号 --point-figures sparse   要点截图密度：all 全部 / sparse 隔一取一 / off 关闭
  VIDAR-CLI.exe pdf BV号 --style paper --scale compact --open   改完直接打开
  图形界面里点「预览排版…」：内嵌 PDF 预览 + 参数面板，随改随看。

【输出文件命名】（全部为「<变体>版-视频标题」）
  笔记版-标题.md / 报刊版-标题.pdf / 论文版-标题.pdf / Word版-标题.docx /
  大纲版-标题.md / 原始稿版-标题.md / 精修稿版-标题.md / 元数据版-标题.json

【LLM 配置】
  任意 OpenAI 兼容服务；Key 可放环境变量（如 OPENCODE_GO_API_KEY），
  或在图形界面「设置」里填写（保存到本目录 config.toml）。

【目录说明】
  output\   最终 Markdown 知识文档
  work\     中间产物（支持断点续跑；处理完默认删除音视频）
  logs\     运行日志

【硬件】
  建议 NVIDIA 显卡（运行 gpu install 后启用；无独显自动回退 CPU）；
  音频解码无需 ffmpeg（内置 PyAV）。
