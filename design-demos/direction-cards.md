# 方向卡 · VIDAR v0.15 重设计

约束：Apple HIG 的“轻盈通透”在桌面工具里的三种诠释；同一套真实内容（任务 / 队列 / 规范）。
共同底线：浅色默认、深色同等品质（落地时补齐）、单一强调色、状态 = 图标 + 颜色 + 文案、正文 ≥12.5px。

---

## 1. Clear Glass（完整稿 · 方向 A）

- **一句话**：macOS 26 式的清晰玻璃——浮动窗口、柔和紫、内容卡片保持实底。
- **结构**：左侧 218px 半透明侧栏 + 单列主区；任务页 = 流程时间线 + 实时日志 + 产物。
- **强调色**：品牌紫 #6C5CE7，玻璃只出现在侧栏与底部操作条。
- **强项**：品牌识别最强；层级柔软；空状态容易做得好看。
- **风险**：玻璃与阴影容易滑向“装饰”；Qt/QSS 实现半透明与模糊代价高，需降级为浅色分层。
- **适合**：想让 VIDAR 看起来更像“消费级精品软件”。

## 2. Paper Studio（完整稿 · 方向 B）

- **一句话**：把界面做成一张编辑桌——纸白、发丝线、宋体标题、钢蓝一点。
- **结构**：顶部报头式导航（无侧栏）；任务页 = 左侧流程 + 右侧实时“校样”，文档本身就是主角。
- **强调色**：钢蓝 #2F5FE0，只给当前步骤与主操作。
- **强项**：与“视频 → 文档”的产品本质最贴合；结果可感知；排版气质独树一帜。
- **风险**：顶部导航在页面多时扩展性弱；宋体在 Windows 小字号下质感不稳，需限定使用场景。
- **适合**：把“读文档”当作核心价值，而非“跑任务”。

## 3. Quiet Monochrome（完整稿 · 方向 C）

- **一句话**：灰度承载信息，紫色只回答“现在在哪”。
- **结构**：56px 图标栏 + 234px 任务列表 + 主工作区；横向步骤条 + 日志表 + 右侧参数栏。
- **强调色**：紫 #7C5CFF，面积 <5%。
- **强项**：密度与扫读效率最高；批量/长时使用最稳；最像“专业工具”。
- **风险**：气质偏冷；首屏惊喜感弱；三栏在 980px 最小宽度下需要折叠策略。
- **适合**：重度用户、批量处理、长时间挂着跑。

## 备选（未做完整稿）

4. **Editorial Dark**：深炭底 + 暖灰字 + 琥珀强调，文档居中如阅读器。与“浅色默认”相悖，留作深色皮肤参考。
5. **Studio Whiteboard**：把流水线画成节点图，步骤之间可拖拽。信息密度低、认知负担高，暂不采用。
6. **Command Line**：等宽字体主导、命令面板优先。目标用户非技术型，排除。

## 评审结论（自评）

- 三稿在结构上真正分开（侧栏 / 顶栏 / 三栏），不是换色。
- 三稿都用真实内容与真实状态（运行中、完成、失败），没有 lorem。
- 共同缺口：深色稿未画（落地时按各方向 token 推导）；200% 缩放与键盘路径未验证。
