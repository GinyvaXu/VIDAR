## 补充要点

- 日常选题约半小时到1小时完成，目标是确定性爆；爆款为百万播放、几万点赞。
- 开头照抄原爆款一个字不改，一直抄到句号；不要只卡前三秒。
- 列观点以个人价值观为唯一标准；借鉴原爆款不超40%，可摘高赞视频与评论区重组。
- 列观点三种方式：原视频观点、类似选题热门视频观点、评论区热评观点。
- 超三分钟视频每15秒有10到12次滑走机会，需设情绪钩子；表现力训练最好对镜说一小时。
