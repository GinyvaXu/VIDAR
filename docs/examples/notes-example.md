# 不要拍段子，老老实实做口播，一条视频教会你做爆款文案！

> **一句话结论：** 口播四步法：选题抄开头、列观点、填内容，用确定性选题与表现力训练做爆款。

## 核心要点

1. 口播文案四步走：选题、抄开头、列观点、填内容，另需镜头表现力。（[00:00](https://www.bilibili.com/video/BV1ed7q63EVZ?t=0)）
2. 选题本质要确定性；短视频是给平台算法看的；每天口播类至少500万人创作。（[00:43](https://www.bilibili.com/video/BV1ed7q63EVZ?t=42)）
3. 新号前一个月蹭热点；选题至少占一半时间，选对就成功50%，需与价值观一致。（[03:30](https://www.bilibili.com/video/BV1ed7q63EVZ?t=210)）
4. 日常选题约半小时到1小时完成，目标是确定性爆；爆款为百万播放、几万点赞。
5. 开头照抄原爆款一个字不改，一直抄到句号；不要只卡前三秒。
6. 列观点以个人价值观为唯一标准；借鉴原爆款不超40%，可摘高赞视频与评论区重组。
7. 列观点三种方式：原视频观点、类似选题热门视频观点、评论区热评观点。
8. 超三分钟视频每15秒有10到12次滑走机会，需设情绪钩子；表现力训练最好对镜说一小时。
