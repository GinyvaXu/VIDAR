# PRODUCT.md — VIDAR

> 由 v0.15.0 重设计启动时整理；事实来自 README、源码与 2026-11-22 的三轮产品问答。

## 一句话

把 B 站视频变成可读、可检索、可打印的知识文档：本地 ASR + 大模型精修，输出 Markdown / PDF / EPUB。

## 用户

- 主要：中文知识工作者、学生、研究者、内容整理者。
- 场景：看到一条有价值的视频，想要一份能划重点、能搜索、能打印、能给朋友看的文档。
- 设备：Windows 10/11 笔记本或台式机；可能有 NVIDIA 显卡（4–8 GB 显存），也可能只有 CPU。
- 技术水平：会用大模型 API，但不一定懂 Python / 命令行。

## 核心任务（按频率）

1. **单条转换**：粘贴链接 → 看进度 → 拿到文档（最高频）。
2. **批量转换**：贴一列链接或导入文件 → 排队跑完 → 统一取结果。
3. **回访与再导出**：找到上周的结果，换格式再导出，或从失败那一步续跑。
4. **环境维护**：下载/校验 ASR 模型，配置 LLM 供应商，确认磁盘与显存。

## 产品真相（不可在重设计中丢失）

- 六步流水线：解析 → 下载音频 → 解码 → ASR → 精修 → 广告识别 → 摘要/翻译 → 渲染导出。
- 断点续跑与暂停释放显存是核心能力，不是边缘功能。
- 结果不是一次性弹窗：产物落在输出目录，历史里可再次打开/续跑。
- 本地优先：ASR 在本机跑，LLM 可选；密钥只存本机。
- 中文界面，Windows 桌面应用（PySide6/Qt），无 WebView。

## 约束

- 默认窗口 1180×760，最小 980×640；单屏笔记本要能舒服使用。
- 明暗双主题同等品质，默认跟随系统、可手动切换。
- 不新增重型依赖；动效用 Qt 原生能力实现。
- 旧 `output/` 历史与 `config.toml` 允许一次性迁移，但不能要求用户重跑任务。

## 不做什么

- 不做在线账号体系、云同步、社区。
- 不做视频剪辑/播放器。
- 不为“看起来高级”引入玻璃拟态堆叠、渐变光斑、无意义图表。

## 成功标准

- 首次打开 5 秒内知道“粘贴链接就能开始”。
- 失败时能在当前页面看懂原因、知道下一步点哪里，不需要读日志。
- 批量 20 条任务时，状态、进度、失败项一眼可辨。
- 明暗两套截图并排看不出“哪套是附赠的”。
