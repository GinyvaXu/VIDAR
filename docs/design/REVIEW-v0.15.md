# UI 复审 — VIDAR v0.15.0（Clear Glass）

对象：`work/design/v015-iter1…iter6/` 的 18 张实拍（6 页 × 明暗 + 运行/失败态），以及 `work/design/v015-min2/` 的 980×640 最小窗口。
方法：ui-taste 评审表 + impeccable 的 Operate 判据；对比基线 `AUDIT-v0.14.md`。

## 结论

- 基线：**BLOCK（36/65）**
- 现状：**PASS WITH NOTES（50/65）**，无 P0。
- 主要剩余项是动效与极端状态（P1），不是结构问题。

## 本轮修掉的 P0

1. **错误弹窗遮挡上下文** → 页内错误卡，保留步骤与日志可见，提供「从失败步骤重跑 / 修复模型配置 / 复制错误」。
2. **状态不可扫读** → 时间线圆点 + 状态色 + 文案；队列/模型/资料库同步语义色。
3. **浅色主题里的纯黑日志** → 浅底等宽日志卡，长行任意位置换行。
4. **空状态缺失** → 队列、资料库、最近任务均有引导文案与图标。

## 多轮迭代记录

- **iter1**：新壳首拍。发现任务页左右溢出、设置入口图标失控、规范页裁切。
- **iter2**：修溢出与图标；补运行/失败态截图；发现进度条文字压色块、资料库按钮裁切。
- **iter3**：隐藏进度内嵌文字、按钮缩短、表头左对齐、队列空态；发现空态文字被裁、时间线在错误卡下溢出。
- **iter4–5**：内容区滚动、空态自适应、步骤列中文标题（键名入 UserRole）、队列空态居中。
- **iter6**：最小窗口 980×640 复核；日志换行、错误卡与操作条不再互相遮挡。
