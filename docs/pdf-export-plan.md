# VIDAR PDF / 配图导出方案 v1.0（已实现）

> 目标：把视频变成**可打印的图文文档**——比 Markdown 更强的可读性，图文并茂、适合直接打印阅读。
> 定位：`notes.md` 负责"知识库/可检索"，`notes.pdf` 负责"阅读与打印"，`notes.docx` 负责"可再编辑"。
> 状态：✅ 已实现（v0.4.0）；本文档保留为设计与验收依据。

## 0.1 实现说明（与设计稿的差异）

- 报刊风配图统一为**单栏宽**（跨栏排版留作后续增强；85mm 宽在 720p 源下约 300dpi，打印足够）
- 金句与章节小结重复时**自动去重**（避免排版冗余）
- 模型偶发省略配图锚点时自动**追加一次强约束请求**（仅整片无锚点时触发）
- 论文风目录采用 `multiBuild` 两遍渲染（章节计数逐遍重置，避免目录条目不收敛）
- Markdown 内嵌图片、二维码/时间索引：**本期未做**（预留）

## 0. 已确认决策（本次评审）

| # | 决策 | 结论 |
|---|------|------|
| 1 | 模板 | **两套都做**：报刊风（newspaper）+ 论文风（paper），命令行/配置切换 |
| 2 | 正文档位 | **默认全文**（含完整精修稿，10–16 页）；`--pdf-mode brief` 可输出精简版 |
| 3 | 首页主图 | **B 站封面图**（yt-dlp 元数据自带，无需抽帧） |
| 4 | 截图 | **720p** 视频抽帧；**数量与位置由 LLM 分析决定**（按内容实际需要，不设硬上限，软上限 40） |
| 5 | 附加产出 | **Word 导出（.docx）**；二维码/时间索引本期不做（预留）；Markdown 内嵌图片预留开关（默认关） |
| 6 | 字体 | **内置思源宋体子集**（OFL，俩字重，约 10MB），跨机器排版一致 |

## 1. 内容映射（视频元素 → 文档元素）

| 数据来源 | 文档元素 |
|----------|----------|
| meta（标题 / UP / 时长 / 发布日期 / BV号） | 报头元信息条 / 论文标题区 |
| B 站封面图 | 报刊风第 1 页主图（图 1）；论文风可省略 |
| `summary.one_liner` | 导语（报刊）/ 摘要首句（论文） |
| `key_points`（带时间戳） | 「本期看点」要点框 / 摘要要点 |
| `chapters`（标题 / 时间 / 小结 / 金句） | 章节标题 + 章节导语 + 引用块 |
| `chapters[].figures[]`（**新增**：anchor + caption） | 配图与图注（LLM 决定数量与位置） |
| `transcript.refined`（**默认全文**） | 正文主体（按章节分组） |
| 原视频链接 | 页脚/尾注（打印版不做超链接跳转） |

> `chapters[].quote`（章节金句）与 `chapters[].figures[]` 均在 summarize 阶段顺带产出，**不增加 LLM 调用次数**。

## 2. 关键帧（截图）设计

- **选点**：reduce 阶段让 LLM 为每章输出 `figures: [{anchor: 段号, caption: 一句话说明}]`（可为 0 张；依据"该处是否有值得展示的画面/演示/图示"判断），本地把 anchor 映射回时间戳
- **抽帧来源**：截图启用时下载 720p 视频流（20 分钟约 150–250MB，瞬时占用，抽完即删）
- **去重**：dHash（8×8 灰度指纹）+ 汉明距离，剔除同画面重复；相邻配图最小间隔 15s（可配）
- **规格**：JPEG q85，宽度 1280；单张 ≈ 60–150KB
- **软上限**：40 张（超出告警并截断，避免异常长视频把文档撑爆）
- **落盘**：`output/.../images/fig01.jpg` …
- **清理**：抽帧完成后立即删除 720p 视频（遵循"处理完删媒体"策略）

## 3. 版式 A：报刊风（newspaper）

```text
┌──────────────────────────────────────────────────────┐
│ BILIBILI · 22:49 · 胡说老王讲干货 · 2026-06-26        │ ← 元信息条 8pt 字距加宽
│ ══════════════════════════════════════════════════════ │ ← 双细线报头分隔
│     不要拍段子，老老实实做口播，一条视频教会你做爆款文案！    │ ← 主标题 26pt 宋体 Bold
│  ── 口播爆款靠确定选题、照抄开头、列观点填内容，训练镜头表现力 ── │ ← 导语 14pt 灰
│  ┌────────────────────────────────────────────────┐  │
│  │                 [ B站封面图 ]                    │  │ ← 横跨双栏主图
│  └────────────────────────────────────────────────┘  │
│   图 1：视频封面（00:00）                              │
│  ┌────────────────┐ ┌────────────────┐               │
│  │ 本期看点        │ │ 1 · 口播四步与算法逻辑          │
│  │ ① …（01:58）    │ │ 口播文案四步为选题、抄开头、      │
│  │ ② …（04:40）    │ │ 列观点、填内容…（正文 10.5pt）   │
│  └────────────────┘ └────────────────┘               │
│        左栏                  右栏                      │
└──────────────────────────────────────────────────────┘
 BV1ed7q63EVZ                — 1 —                 2026-10-08
```

- 页面：A4 纵向，**双栏**（栏宽 8.2cm / 栏距 8mm）；页边距 上18 下18 左右16 mm
- 正文 10.5pt / 行距 1.65 / 段间距 4pt（**不缩进**，避免双栏断裂处难看）；标题 思源宋体 Bold
- 章节结构（全文模式）：章标题（14pt）→ 章节小结（斜体导语）→ 精修稿正文（按段）→ 金句引用块（左 3pt 竖线）→ 插图（跨栏或单栏）
- **长文规则**：章节标题不孤行（与后文至少 2 行同页）；段落不可跨栏拆散图注；每章最多 3 张图默认排布
- 配图：横跨双栏（重要画面）或单栏；图注 9pt 灰 `图 N：说明（mm:ss）`
- 页眉（第 2 页起）：左 `VIDAR 视频文稿` / 右 短标题；页脚：左 BV 号 / 中 `— N —` / 右 生成日期
- 打印优化：**黑白可读**、无大面积底色、线宽 ≥ 0.5pt、正文 ≥ 10.5pt

## 4. 版式 B：论文风（paper）

```text
┌──────────────────────────────────────────────────────┐
│      用绳子链接即可！为什么要知行合一！                     │ ← 标题 18pt 居中 Bold
│      作者：长欢与大头          整理：VIDAR v0.4.0        │
│      2026-09-27 · 时长 02:19 · BV1MSab65EHG           │
│  ───────────────────────────────────────────────      │
│      摘要        （一句话结论 + 3–5 条要点）             │
│      关键词：三马串联 / 行军 / 冲阵                       │
│  ───────────────────────────────────────────────      │
│      目录                                             │
│      1  三马功能与串绳方法 ………………………………  2          │
│      2  串联后的行军与分工 ………………………………  3          │
│                                                      │
│      1  三马功能与串绳方法                               │
│      1.1 功能差异（全文模式下正文即精修稿，按章分组）        │
│              ┌────────────────────────┐              │
│              │        [关键帧]          │              │
│              └────────────────────────┘              │
│              图 1：三马串联示意（00:48）                  │
└──────────────────────────────────────────────────────┘
```

- 页面：A4 纵向，**单栏**（正文宽 15cm）；页边距 22mm
- 结构：标题区 → 摘要（细边框，不用底色）→ 目录（带页码，两遍渲染）→ 编号章节 → 尾注（原视频链接）
- 正文 11pt / 行距 1.5 / 段间距 6pt；时间引用 `[00:48]` 小号灰
- 图：居中，宽 ≤ 12cm，图注 9pt 灰居中
- 页眉：左 短标题 / 右 `VIDAR`；页脚：居中页码

## 5. 正文档位

| 档位 | 内容 | 20 分钟视频页数 |
|------|------|----------------|
| **全文（默认）** | 导语 + 要点 + 每章：小结 + 完整精修稿正文 + 配图 | 10–16 页 |
| 精简 | 导语 + 要点 + 章节小结 + 配图 | 3–6 页 |

CLI：`--pdf-style newspaper|paper`、`--pdf-mode full|brief`；配置：`[export] pdf / pdf_style / pdf_mode`

## 6. 技术选型

| 环节 | 方案 | 体积成本 |
|------|------|----------|
| PDF 渲染 | **ReportLab（纯 Python）**：双栏 frames、TOC、页眉页脚、图注、图片流 | +10MB |
| 抽帧/缩放 | PyAV（已有）+ Pillow（缩放/JPEG 编码/封面处理） | +4MB |
| Word 导出 | python-docx（+lxml） | +6MB |
| 字体 | 思源宋体 SC 子集 Regular/Bold（OFL 授权；构建期 fonttools 子集化：GB2312+常用标点+拉丁） | +10MB |
| 备选（不采用） | HTML→PDF（内置 Chromium 排版最灵活但 +130MB，与瘦身目标冲突） | — |

> 便携包 zip 预计：160MB → **约 190MB**。
> 字体来源优先级（构建期脚本 `scripts/prepare_fonts.py`）：jsDelivr CDN → GitHub（gh-proxy）→ 官方源；产物提交到 `src/vidar/assets/fonts/` 并由 spec 打包。
> 子集字体许可：思源宋体为 SIL OFL 1.1，允许随包分发（附 OFL 文本）。

## 7. 流水线集成

```
… → summarize → [frames]（新增第 9 步）→ export
                     ├─ 下载 720p 视频（仅截图启用时）
                     ├─ 按 LLM figures 锚点抽帧 + 去重 + 存 images/
                     └─ 删除 720p 视频
export 产物：notes.md（不变）+ notes.pdf（可选）+ notes.docx（可选）+ images/*.jpg
```

- 新增配置：`[export] screenshots=true / pdf=true / pdf_style / pdf_mode / docx=true / max_images=40 / video_max_height=720 / images_in_markdown=false`
- 增量耗时：下载 720p ≈ 20–60s + 抽帧 ≈ 10s + 渲染 ≈ 10s → 单条约 +1–2 分钟
- 断点续跑：frames 独立成步，可单独重跑；PDF/DOCX 渲染失败不阻塞 md 导出

## 8. 验收标准

- A4 黑白打印可读：正文 ≥ 10.5pt、无截断/溢出/孤行
- 中文正确嵌入（PDF 可复制文本、无乱码）
- 图注与时间戳正确；截图与章节内容不错位
- 20 分钟视频：全文版 PDF ≤ 8MB；渲染 ≤ 30s
- `notes.docx` 可在 Word/WPS 中正常打开与编辑
