# VIDAR v1.0.0

把 B 站视频变成可读、可检索、可打印的 Markdown 知识文档（本地识别 + 大模型整理）。

这是 VIDAR 的**首个正式版**，整合了 v0.15.0 的 Clear Glass 六页重构与 v0.15.1 的五路子智能体审验修复。

## 本版亮点

### 🎨 Clear Glass 六页重构
- 工作台 / 任务 / 队列 / 资料库 / 模型 / 设置六页信息架构
- 浅色默认、深色同等品质；单一品牌紫、发丝线分层、7/10/16/22 四级圆角
- 任务页 12 步纵向时间线；页内错误卡给出「原因 + 人话解释 + 重跑 / 修复 / 复制」
- 980×640 最小窗口可滚动；高 DPI 图标与下拉箭头

### 🔧 五路子智能体审验修复
- **配置保存崩溃**：`None` 字段写入 TOML 触发 `TypeError`——已修复
- **任务目录串档**：载入历史后改链接不再写进旧目录
- **畸形 state.json**：不再导致启动崩溃
- **模型位置与自愈**：list / check / doctor / 运行时统一判定；preprocessor 按 `feature_size` 语义校验
- **队列持久化**：BOM 容忍、损坏备份、原子写、`running` 归一、全状态去重、启动不覆盖
- **线程生命周期**：连接测试/预览关闭不再有崩溃风险
- **对比度**：深色主按钮 4.86:1，次要文本与表头达到可读标准

## 安装 / 使用

- **便携版**：下载 `VIDAR-v1.0.0-win64-portable.zip`，解压到任意目录，双击 `VIDAR.exe`
- **ASR 模型**（约 3GB，不随包分发）：`VIDAR-CLI.exe model download large-v3`，或把模型放进 `models/`
- **GPU 加速**（N 卡可选）：`VIDAR-CLI.exe gpu install`
- **LLM**：首次启动有接入向导（OpenCode Go / DeepSeek / 硅基流动 / Kimi / 智谱 / Ollama）

## 已知限制

- 模型不随包分发；首次使用需下载或放置模型
- 队列暂无行内进度条；页面切换无过渡动画
- TOML 重写会丢注释与未知段；b23 短链与 BV 直链仍生成不同任务目录
